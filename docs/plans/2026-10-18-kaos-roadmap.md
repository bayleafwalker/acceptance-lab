# acceptance-lab: KAOS-derived delivery plan

Status: operator-requested planning scope, 18 October 2026. Implementation, onboarding and qualification remain separate work.

This owner addendum implements the [two-year KAOS backcast](https://github.com/bayleafwalker/agentops/blob/main/docs/plans/agentops/2026-10-18-kaos-2028-roadmap.md) and preserves existing owner plans and October15/17 trust boundaries. Served references own execution status; this file records requirements. No new runtime, purchase or live deployment is implied.

## Delivery protocol

For each item: reconcile current source/observations and existing work; specify responsibility, sourcing and failure cases; implement/configure missing parts; qualify success/refusal/recovery; release/onboard under existing authority; verify use/outcomes/burden and document support/rollback/export. Source, released, deployed, field-qualified and accepted are distinct. Dependencies order work, without calendar promises.

## AL-K01 — Reconstructible accepted results

**Goal / feature / sourcing:** G07 / F07 / build. **Served item:** acceptance-lab#2685.

**Current state / gap:** Prototype deterministic scenarios and append-only records exist; no production policy authority.

**Work:** Build representative held-out cohorts from real accepted/failed work; define mechanism, quality, authority and economics criteria; calibrate subjective rubrics with humans; version scorer and corpus together.

**Predecessors:** AO-K02

**Acceptance:** Known bad authority/effect/budget cases fail even if prose quality is high; repeated trials and denominators are reported; candidate cannot alter its own oracle; model judges cannot override hard gates.

## AL-K02 — Outcome-linked learning

**Goal / feature / sourcing:** G11 / F11 / build. **Served item:** acceptance-lab#2686.

**Current state / gap:** Existing baseline/candidate comparison is prototype evidence; extraction into Vuoro requires two real consumers.

**Work:** Run one local-inference and one HLA or creative campaign; compare accepted outcomes, uncertainty, rework and review cost; evaluate whether shared event contract merits adapter adoption, retention or consolidation.

**Predecessors:** AL-K01, LI-K01

**Acceptance:** Two consumers demonstrate decision value and measured burden before shared extraction; insufficient sample is inconclusive; no experiment result automatically promotes production policy.

## Boundaries

This adds no effect authority. Execution and model choice remain native; protected effects retain their owners; content never grants permission. Qualify existing products before duplicating them. Preserve original evidence, explicit unknowns, human domain acceptance and current source/live distinctions.
